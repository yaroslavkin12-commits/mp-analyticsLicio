## Подготовленные изменения — ещё не развёрнуты

Перенос сначала восстанавливает отдельную базу, прекращается при ошибке и сверяет точные количества строк. Переключение требует --activate; предыдущая база сохраняется под новым именем для отката. Проверка количеств сравнивает источник уже после снимка, поэтому при изменениях источника возможен безопасный отказ и необходимость повторения. Это не замена остановке записи на время окончательного переноса.

Автообновление больше не запускает повторный импорт по migrate.stamp. Bootstrap обозначает завершение настройки как configured вместо ложного ready.

Проверен синтаксис shell. Реальное восстановление и переключение ещё не проверены; до восстановления доступа изменения не следует выкладывать в main.
