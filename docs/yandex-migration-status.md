## Перенос базы пока не завершён

Первая безопасная подготовка восстановила отдельную локальную базу, но сверка отказала: источник изменился между созданием снимка и подсчётом строк. Она не была активирована. Последняя версия dump-snapshot.cjs сравнивает строки в том же экспортированном снимке PostgreSQL, что и pg_dump. Эта версия опубликована, но окончательный перенос по ней пока не выполнен.

Импорт использует отдельную базу, прекращается при ошибке и по умолчанию не переключает приложение. Активация требует --activate; прежняя локальная база сохраняется для отката. Автообновление не запускает импорт по migrate.stamp. На сервере cloud-init временно устанавливает Neon как рабочий источник при загрузке; перед окончательным переносом нужно заменить этот временный механизм, иначе перезапуск вернёт Neon.

Резервное копирование исправлено: источник берётся из действующего app.env, а не из старой локальной строки подключения. Архив заменяется только после успешного создания и проверки списка; при ошибке прежняя копия сохраняется. Смена скрипта запускает одну проверочную копию в фоне. Проверены синтаксис и сценарии успеха/ошибки с подменным pg_dump; Настоящая копия рабочей базы успешно создана 14.11.2026 в 11:38:22 UTC: 30 741 072 байта, backupDatabaseMode=neon-shared, backupExit=0, backupError пуст. Проверен список содержимого архива; полное восстановление этой копии ещё не проверялось.
