# Независимая история магазинов

Нижняя таблица сводки не получает даты верхнего календаря. Её фильтры — категория, магазины и переключатель «Недели / Месяцы». По умолчанию показываются текущая неделя и предыдущие периоды; прокрутка назад догружает всю имеющуюся историю. Недели идут с понедельника по воскресенье, месяцы — от первого до последнего календарного дня.

`GET /api/sales/history` (для WB — `/api/wb/views/sales/history`) принимает `cabinet`, `mode`, `category`, необязательный `end`. Возвращает компактные итоги и сравнения, границы источников и курсор `olderThan`. Один запрос охватывает восемь недель либо два месяца плюс предшествующий период для сравнения; это укладывается в ограничение существующих загрузчиков 92 дня. Запросы сериализованы, кэш ограничен 24 ответами и двумя минутами, учитывает версию данных и разрешённые артикулы. Исходные данные в браузер не передаются.

Формулы переиспользуют `shopDaily`, `pnlTotals`, `unitCoefs`, `unitProfit`. Финансовые данные сначала обрезаются по нужному периоду с переиндексацией дней, затем применяется существующее распределение общих удержаний. Прогноз использует действующие коэффициенты юнит-экономики, как верхняя таблица. Средние по магазинам взвешиваются по количеству, а не усредняются напрямую.

Завершённый период сравнивается со всем предыдущим календарным периодом. Неполный — с такими же днями предыдущего; если предыдущий месяц короче, сравнение ограничено общей длиной, даты видны в подсказке. Порог ±5% включительно — жёлтый; улучшение — зелёное; ухудшение — красное. Для расходов направление обратное. При нулевой базе показывается «с 0» вместо бесконечного процента.

Заказы, финансы и реклама имеют отдельные границы загруженных данных. Дни за этими границами не превращаются в нули. Неполные значения помечены; при отсутствующем предыдущем периоде процент не рассчитывается. Для суммы магазинов неизвестный показатель хотя бы одного магазина остаётся неизвестным. В ограниченном профиле артикулы фильтруются до расчёта итогов; серверная проекция требует подтверждения этой фильтрации.

Текущие столбцы обновляются раз в пять минут, сохраняя загруженную историю и прокрутку. Переключение браузерной вкладки и верхнего календаря не сбрасывает таблицу.
