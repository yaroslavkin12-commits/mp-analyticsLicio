# Общий налог магазина

Настройка находится в «Товары → Налог»: учитывать налог и ставка в процентах.
Сохранение явное. Отключение сохраняет ставку, но передаёт в расчёты 0%.
Настройка отдельная для каждого магазина и действует на все периоды, включая прошлые.
Сами начисления Ozon, себестоимость и зафиксированные планы не переписываются.

Источник после первого сохранения — `app_settings`, ключ `tax:<cabinet>`,
значение `{enabled, rate}`. API: GET/POST `/api/settings/tax`, кабинет в query/body.
Ответ содержит `effectiveRate` и `configured`; GET не кэшируется браузером.
Ставка должна быть числом от 0 до 100, enabled — boolean, кабинет проверяется.

Общий клиентский модуль — `dashboard/src/lib/taxSettings.js`. Все открытые страницы
подписаны на него; сохранение сразу запускает их пересчёт. На других компьютерах
настройка перечитывается при фокусе окна и раз в минуту для открытых разделов.
В localStorage хранится только последняя серверная настройка для повторного открытия.
До первого явного сохранения прежняя локальная ставка `mp-tax-<cabinet>` сохраняет
действие; в её отсутствие используется 6%. После сохранения старое локальное значение
не учитывается. Telegram также сохраняет прежнюю ставку до первой общей настройки.

P&L, аналитика, РНП, ABC, юнит-экономика, цены и маржа, конструктор, выгрузки,
реклама и сводка магазинов используют общую эффективную ставку. В рекламе ставка
входит в зависимости кэшей модели и сортировки по прибыли. Калькулятор при отключении
принудительно использует 0%, даже если в сценарии осталась ручная ставка.
При включённом налоге калькулятор по-прежнему позволяет моделировать другую ставку.
Утренний Telegram-дайджест читает общую настройку на сервере перед расчётом.
Планирование уже рассчитывало свои показатели без налога; его методика не меняется.

Проверки: `node --test backend/test/*.test.cjs`, сборка dashboard, браузерная
проверка отключения/включения, разницы прибыли на сумму налога, прогнозов рекламы,
повторного открытия и отдельного браузера. Рабочие настройки при проверке не менять.
